THE SIMPLE ROUTE

从截图，到确认。

把容易变化的识别逻辑交给服务，熟悉的操作留在手机里。

01 / CAPTURE

截取付款详情

在账单页面运行快捷指令，获取截图以及 iCost 中的分类和账户。

02 / UNDERSTAND

整理交易信息

服务调用模型识别交易，并检查金额、时间、分类和账户。

03 / CONFIRM

核对后再入账

在手机上检查识别结果，确认后跳转 iCost。每一笔都由你做主。

SETUP GUIDE

装好它，只需一次。

从安装到第一笔记账，跟着这三步走。所有填写项设置一次即可，之后随时可以在快捷指令里修改。

01 / PREPARE

准备两样东西

在 iPhone 上安装并设置好 iCost：至少建好你的支出分类、收入分类和账户。再拿到你的服务访问凭据（授权码），由部署者提供。

02 / INSTALL

安装并填写

点击上方「安装快捷指令」，在快捷指令 App 中点「添加快捷指令」，按提示填写下方四项设置，一路确认完成。

03 / RECORD

记第一笔账

在付款账单详情页运行快捷指令，几秒后弹出记账小票；核对金额、时间、账户与分类后确认，自动跳转 iCost 入账。

服务访问凭据必填 · Access Key
粘贴你的个人授权码。它只用于访问 CostBridge 服务，不是模型密钥，也不会被网页保存。请勿分享给他人——凭据等同于你在这项服务里的身份。
iCost 默认账户必填 · Default Account
当账单上认不出账户时，用它兜底。名称必须与 iCost 中的账户完全一致（包括空格和括号），例如「招商银行储蓄卡」。不一致时小票会出现 ⚠️ 提醒，按提醒修改后重试即可。
自定义提示词选填 · Custom Rule
写一段自然语言规则，例如「Apple Pay 支付时使用信用卡」。规则由模型结合账单内容判断，结果请核对；留空表示不启用额外规则。
模型供应商选填 · Provider
默认已填 groq：主模型失败时自动切换备用，无需改动。填 qwen 或 sf 则只调用所选供应商、不再自动切换，适合单独测试某个模型；响应中的 provider 字段会标明实际使用的是哪家。

小票上出现 ⚠️ 或「请核对」时，说明模型拿不准，务必人工确认后再入账。需要修改设置时，打开「快捷指令」App，点击该指令旁的 ⓘ 即可重新填写。
